# Loi n° 70-634 du 17 juillet 1970 insérant dans le Code pénal un article 462 réprimant le détournement d'aéronef (1).

## Article 2

La présente loi est applicable aux territoires d'outre-mer sous réserve de remplacer les mots : "de la réclusion criminelle", par les mots : "des travaux forcés".
